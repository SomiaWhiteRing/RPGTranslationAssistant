# RPG制作大师校对工具 v4.5.0

面向 RPG Maker 2000/2003 翻译文本的多格式校对工作台。支持 WindyTranslator 风格 JSON、`StringScripts_Origin` + `StringScripts` TXT 双目录，以及 TranslationTables Excel 文件夹。

## 从 WindyTranslator 小工具启动

启动后自动加载当前文本，并依次运行宽度、说话人、引号、句末符号、标点统计、省略号、英文句号、顿号、空格、大小写、全半角、重复文本和缺译检查，结果显示在各自页面。没有有效数据源时，先选择数据源并点击检查，首次加载完成后自动运行上述检查。各项检查沿用页面当前设置；不会自动应用译文修改或导出报告。首次扫描是否创建备份由“首次检查数据源时自动备份”设置决定。

两种启动方式都会将当前工程工作目录的 `character_dictionary.csv` 和 `entity_dictionary.csv` 作为可选辞典传入：存在时导入“生成辞典”页并运行辞典匹配检查，不存在时跳过。没有类别列的记录使用“其他”类别；辞典有冲突译文时沿用工具的冲突选择提示。数据库对照和版本比较需要另外指定对照文件，由用户手动发起。

命令行可重复传入 `--initial-dictionary <文件路径>`，支持 CSV、XLSX 和 XLSM。使用自定义辞典文件名时，可修改 Manifest 对应的 `source`，或通过此参数传入。


## v4.5.0 本轮重点更新

### 1. 标点符号处理拆分为三个独立专项页

“英文句号结尾”“句中顿号”“空格检查”不再共用句末符号页中的一个按钮，而是作为“标点符号处理”下的三个独立子页。原有“句末符号”页只负责句尾句号/问号/感叹号/分号等同步。

**英文句号结尾**：只列出“译文以半角 `.` 结尾、但原文不是半角 `.`”的记录。原文与译文都以 `.` 结尾视为正常，不进入列表。提供“全选原文不是英文句号”“全选原文是 `。`”以及可选的 `. → 。` 预览/应用。

**句中顿号**：按四类同时标记：一行末尾的顿号、顿号前后同字、同一文本有多个顿号、其他情况。可以按分类快速全选；可选择“整条译文所有顿号改为逗号”，也可以只替换每行末尾的顿号而不动句中其他顿号。

**空格检查**：区分原文行首空格、译文行尾空格、文本中间空格不一致，以及“查看所有含空格文本”。行首空格只做保守补齐；译文行尾空格可以删除，并可设置“如果原文同行也有行尾空格则保留”；文本中间空格差异只报警、手动处理。

### 2. 宽度页与单独文本处理改为上下三区域拖动

两个页面都采用“列表/上下文 → 原文+译文 → 当前字体宽度参考”的纵向三段布局。新增两条水平拖动条，用来调整三个纵向单元的空间。原文/译文之间仍保持左右并排，但不会再依赖中间横向分隔来解决垂直空间。

原文/译文区和字体预览区设置了最小高度。即使开启“列表显示分行”，上方列表变高，也不会把编辑框压缩到一行或完全挤没。原有“隐藏原文译文部分/隐藏当前字体预览”和数值高度设置继续保留。

### 3. 生成辞典增加快速查询

“生成辞典”页新增查询框，可以按原文、译文、类别、来源快速过滤当前辞典表格。过滤只改变显示，不改变辞典内容；表格行仍使用原始索引，因此过滤后更新、删除、编辑的仍是正确的原记录。

### 4. 错误译名自动替换增加原文辞典词硬约束

错误译名只有同时满足以下两个条件才允许进入自动替换：

1. 译文中命中已登记的错误译名；
2. **原文中实际包含这个错误译名所属的“对应辞典原词”**。

例如错误译名 `当前理智值 → 当前理智度` 绑定辞典原词 `現在正気度`，那么只有原文确实含 `現在正気度` 的句子才能自动修改。其他句子即使碰巧出现“当前理智值”，也不会被这条规则改动。没有“对应辞典原词”的旧错误译名表条目可以继续导入和查看，但不会无条件全局自动替换。

### 5. 批量校对报告同步采用新专项规则

批量报告中的英文句号、顿号、空格检查现在和交互页面使用同一套 v4.5 规则，避免页面已经判断为正常、报告却仍然报警的情况。

## v4.4.0 本轮重点更新

### 1. 错误译名流程改为“人工待确认”与“自动替换”严格分流

以辞典词 `現在正気度 → 当前理智度` 为例：

- 人工发现 `当前理智值` 是错误译名后，划选并加入错误译名；
- 所有能够由 `当前理智值 → 当前理智度` 自动处理的辞典警告会**立即从人工待确认列表消失**；
- 这些文本会进入“自动替换预览”，用户仍可逐句取消；
- 只有点击“重新检查”时，已经由错误译名管理的警告才会重新回到人工待确认列表。

这样人工检查不会反复看到已经建立自动修正规则的同一种错误。

### 2. 正确译名保护，防止“当前理智度度”

错误译名替换现在具有两层保护：

1. **错误译名最长优先**：如 `沃塔莉` 与 `沃塔` 同时存在，先识别更长的 `沃塔莉`；
2. **正确译名保护区**：所有已知正确译名在替换前先标记保护，短错误词不能在正确译名内部再次命中。

例如：

- `当前理智值 → 当前理智度`
- `当前理智 → 当前理智度`

已经正确的 `当前理智度` 保持不变，不会变成 `当前理智度度`。

### 3. 错误译名支持“单个辞典条目 / 全辞典”两种识别

“匹配辞典检查”新增：

- `逐句识别：当前辞典条目`
- `逐句识别：辞典全部条目`

单条模式只处理当前选中的辞典原词，其自动替换预览也只扫描原文中含这个辞典原词的文本；全辞典模式则处理全部当前辞典警告。

人工审核窗口中的：

- 待确认列表；
- 错误译名列表；
- 自动替换预览列表；

都使用主程序统一表格组件，因此支持：

- 点击表头排序；
- 右键按列筛选；
- 隐藏 / 显示列；
- `Ctrl+C` 复制；
- 当前可见行全选 / 全不选。

### 4. 错误译名可以选择性导出、以后重新导入

错误译名表格式：

| 错误译名 | 正确译名 | 对应辞典原词 | 来源 |
|---|---|---|---|

支持 CSV / XLSX。

导出时可以：

- 先按“对应辞典原词”筛选，只导出某一个词的多个错误译名；
- 或逐项勾选任意错误译名；
- 全选只作用于当前筛选后可见的行。

之后可在其他项目直接导入错误译名表继续使用。

### 5. 检查文本宽度：修正 East Asian Ambiguous 字符误差

RPG Maker 操作符仍会先按显示效果处理：

- `\.`、`\|`、`\!` 等等待/控制操作符不占文本宽度；
- `$r` 等会生成可见字符的操作符按其可见字符计算；
- `\N[n]`、`\V[n]` 等运行时内容继续与“当前字体像素预览”分开判断。

v4.3 及更早的理论宽度算法依据 Unicode East Asian Width，把 `A (Ambiguous)` 字符固定当作 1 个全角单位。部分字体中的 `·` 等字符实际上较窄，会造成理论单位偏大。

v4.4 新增：

`Ambiguous字符单位：0.5 / 1.0`

默认 **0.5**。

因此样本：

`否定权在我们手里是没有的，\.也就是说···`

隐藏 `\.` 后可见为：

`否定权在我们手里是没有的，也就是说···`

- 旧模型：17 + 3×1 = 20 全角单位；
- v4.4 默认：17 + 3×0.5 = **18.5 全角单位**；
- 19 单位理论参考线不再报警。

同时“当前字体像素超线”仍独立存在。如果用户当前选择字体确实把这些字符绘制得很宽，仍会由像素参考线报警。

### 6. 宽度页和单独文本处理页增加框架高度控制

两个页面都可以分别设置：

- 原文 / 译文文本框高度；
- 当前字体预览区域高度；
- 显示 / 隐藏“原文和译文”部分；
- 显示 / 隐藏“当前字体预览”部分。

适合开启“列表显示分行”以后手动腾出更多垂直空间。

### 7. 原文 / 译文文本框直接带宽度刻度

“检查文本宽度”和“单独文本处理”中的原文、译文框上方都增加刻度尺：

- 每 1 个全角单位一个刻度；
- 每 5 个单位标数字；
- 显示有头像和无头像的两条限制线；
- 改字体、改限制值后自动刷新。

当前字体像素预览仍保留，可按需隐藏。

### 8. 当前数据库名称可直接加入生成辞典

“生成辞典”页新增：

`从当前数据库导入道具/怪物/技能名称…`

只读取：

- `Database\Items.txt` 的 `Name`；
- `Database\Monsters.txt` 的 `Name`；
- `Database\Skills.txt` 的 `Name`。

不会导入 Description、UseMessage 等说明文本。

辞典类别新增：

- 怪物
- 技能

### 9. “缺译快速检查”支持“不算缺译”排除表

可以把确认无需翻译、但原译文相同的文本加入“不算缺译”列表。

支持：

- 将当前勾选结果加入排除表；
- 导入排除表；
- 导出排除表；
- 清空排除表。

支持 TXT / CSV / XLSX。排除按**完整原文**精确匹配。

## 继承功能

v4.4 继续保留 v4.3 的：

- JSON / TXT / Excel 三格式统一记录模型与可逆写回；
- 首次扫描备份、手动备份、每 N 次保存备份；
- 文本查询与译文批量替换；
- 文本宽度逻辑线 + 当前字体像素线；
- 单独文本编辑与上下文；
- 说话人识别与稳定译名同步；
- 引号、句尾符号、空格、顿号、标点替换；
- 英文大小写与全半角；
- 省略号按原文匹配；
- 重复文本检查与同步；
- 版本译文字符级差异；
- 可选项目批量校对报告；
- 数据库直接翻译；
- 可编辑 RPG Maker 2000/2003 操作符资料与标点分类文件。

## 运行

Windows 双击：

`启动工具.bat`

首次运行会按需安装 `openpyxl`。

## 打包 EXE

双击：

`打包EXE.bat`

生成：

`dist\RPG制作大师校对工具.exe`

## 测试

双击：

`运行测试.bat`

v4.5 发布包包含旧版本回归测试与 v4.5 专项测试。
